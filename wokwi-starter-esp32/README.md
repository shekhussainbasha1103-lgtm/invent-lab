# InventLab Pro — Wokwi ESP32 LED Starter

This folder is a starter example for importing/creating an ESP32 project in Wokwi. It contains an Arduino sketch, an illustrative Wokwi diagram, and a sample wokwi.toml for a local build workflow.

1. Open https://wokwi.com/esp32.
2. Create an ESP32 project and copy in `sketch.ino` and `diagram.json` (check the current supported board/part IDs in Wokwi).
3. Run the simulation and inspect the serial monitor.

Important: This archive does not include Wokwi's simulator or a compiled firmware binary. The diagram's board/part identifiers and connection syntax may need adjustment to the exact Wokwi template you choose. Verify the wiring and resistor/LED polarity in the editor. Simulation is educational and is not proof of real-hardware safety.
