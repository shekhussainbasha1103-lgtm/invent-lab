Firmware & Simulation Lab

Prepare firmware, export SPICE netlists, and validate workflows before hardware testing.
External toolchain required

Arduino / ESP32 firmware workspace

Edit a starter sketch, then download it as an .ino file. Compilation and uploading happen with Arduino IDE or arduino-cli on your computer; this browser prototype does not compile or flash hardware.

Check the board's pinout, logic voltage and USB driver. Never connect a 5 V signal directly to a 3.3 V-only ESP32 GPIO.

SPICE netlist exporter

Generate a small illustrative ngspice netlist from a simple resistor/source template. This is not a solver; use ngspice or another validated SPICE engine to execute and inspect it.

ngspice official site ↗

Export only. No circuit solver is bundled and no simulation result is claimed.

Recommended local toolchain

  1. Install Arduino IDE from the official Arduino website, or install arduino-cli.
  2. Install the correct ESP32 board package through its official vendor documentation if using ESP32.
  3. Select the exact board and port; compile first, inspect warnings, then upload only to hardware you own or are authorized to use.
  4. For SPICE, install ngspice, save the exported netlist as a .cir file and run it locally. Review convergence warnings and model assumptions.

Firmware compilation/upload and SPICE execution are not run by this static PWA. A future server integration would require a secure sandbox, resource limits and explicit hardware permissions.

    Built-in MCU Simulator

    Write a beginner Arduino sketch and observe virtual GPIO and Serial output inside InventLab Pro.
    Runs in this app
    This is an in-app educational sketch runtime, not a full CPU/peripheral emulator. Supported subset: pinMode, digitalWrite, analogWrite, digitalRead with virtual inputs, delay, Serial.begin/print/println and simple constant pin states. Libraries, Wi-Fi/Bluetooth stacks, interrupts, timers, I²C/SPI devices, native ESP32 binaries and arbitrary C++ are not emulated.

    What this simulator can and cannot do

    Supported now

    Basic GPIO output, PWM-like output values, delay timing, serial text, repeated loop execution and virtual LED feedback.

    Not yet supported

    Full ESP32 silicon emulation, arbitrary compiled firmware, Arduino libraries, realistic analog/SPICE circuits, Wi-Fi/BLE, external peripherals and hardware flashing.

    Next engineering milestone

    A true full-fidelity engine requires a separately licensed/implemented CPU core, board models, peripheral models, compiler integration and extensive compatibility tests.

    ABOUT THE PLATFORM

    Engineering is
    learned by building.

    InventLab Pro is a learning and project-planning workspace for students and makers across ECE, EEE, embedded systems, IoT and research.

    ⚙️

    Current capabilities

    Interactive circuit canvas, wire drafts, simplified educational DC estimates, Boolean logic lab, product-to-circuit designer with schematic and 3D-style concept view, project blueprints, learning tracks, engineering calculators, firmware workspace, local AI-guidance fallback, optional AI backend, local saves and JSON export.

    Advanced integrations still required

    This version includes simplified educational circuit estimates and a Boolean logic lab, not a validated SPICE solver or full ESP32/Arduino firmware emulator. The 3D-style view is illustrative, not exact CAD. Real AI answers require the optional backend and a running local model or configured AI provider. Cloud accounts, collaboration and native Android packaging are not included.

    For serious academic use

    Treat results as learning estimates. For thesis, PhD or safety-critical work, use validated tools, component datasheets, reproducible measurements and supervisor review.
